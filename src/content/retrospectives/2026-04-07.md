## 🎯 오늘 목표했던 것
- ROS 2 (Humble) 워크스페이스 내에서 Google Gemini API를 활용하여 자연어 기반의 거북이(Turtlesim) 제어 및 인공지능 챗봇 노드 구현.
- 노드 내 버그 수정 및 안정화.

## 🚀 새롭게 배운 것
- **ROS 2 Service 아키텍처:** 코드를 실행 후 아무 반응이 없어 멈춘 줄 알았으나, CUI 터미널 입력을 기다리는 것이 아니라 `ros2 service call`을 백그라운드에서 무한 대기하는 서버 역할이었다는 점을 완벽하게 이해함.
- **Turtlesim 동시 실행 타이밍:** 비동기 프로그래밍(`await call_async`) 구조에서 대기 대상인 `turtlesim_node`가 꺼져 있으면 완전한 데드락(무한 대기)에 빠진다는 사실을 깨닫고, 3-Terminal 시스템 구성 매뉴얼을 정립.
- **.bashrc 영구 셋업:** 매번 새 터미널마다 `source setup.bash`를 하지 않으면 `ImportError(.so)`가 발생한다는 점을 알고 기본 셋업으로 등록함.

## 🤔 아쉬웠던 점 / 트러블슈팅
1. **모듈 누락 및 C++ 공유 라이브러리 로드 실패**
   - *문제:* 파이썬 코드 상단에 경로를 주입해도 `libllm_interface_rosidl.so`를 못 찾는 에러 발생.
   - *해결:* `~/.bashrc`에 `source ~/ros2_ws/install/setup.bash` 자동 실행 스크립트를 추가하여 영구 조치 완료.

2. **무/유료 API 분당 제한(Rate Limit) 초과**
   - *문제:* 10회 연속 자동 테스트 중 `429 RESOURCE_EXHAUSTED` (Limit: 5) 발현.
   - *해결:* 무료 API 플랜의 1분당 5회 한도 때문이었음을 확인, 향후 API 연동 시 `try-except`로 대기/재시도 방어 코드가 필수적이라는 교훈을 얻음.

3. **서비스 콜백 반환값 버그**
   - *문제:* `gemini_sample.py` 46번 라인에 문자열(`response.response`)을 직접 반환하는 치명적 버그 확인.
   - *해결:* ROS 2 콜백 규격에 맞추어 `return response` 객체 그 자체를 반환하도록 코드 핫픽스 수정.

- Rate Limiting 딜레이 코드와 에러 핸들링 로직 고도화.
